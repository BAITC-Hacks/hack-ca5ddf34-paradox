# EKT AI-ассистент — HackAlem AI, трек «Торговля»

Проект команды Paradox. Чат-консультант для каталога [ekt.kz](https://ekt.kz): поиск товара, характеристики, остатки по городам, кандидаты в аналоги и добавление в демо-корзину только после явного подтверждения покупателя.

## Запуск backend

Нужны Node.js 20+ и доступ к EKT API и OpenAI API.

```bash
npm install
cp .env.example .env
# Заполните EKT_API_PASSWORD и OPENAI_API_KEY в .env локально.
npm run build
npm test
npm run dev
```

Backend слушает `http://localhost:3000`. `GET /health` проверяет, что сервер запущен. Файл `.env` не коммитить. Если интерфейс запущен на другом порту, настройте proxy `/api/*` и `/cart` на backend: браузер должен отправлять session cookie.

## Запуск frontend

Фронтенд-приложение расположено в папке `ekt-ai-frontend/`.

```bash
cd ekt-ai-frontend
npm install
npm run build
npm test
npm run dev
```

Интерфейс откроется на `http://127.0.0.1:5173`. Сервер разработки проксирует `/api/*` и `/cart` на backend (`http://127.0.0.1:3000`). В `.env` оставьте `PUBLIC_APP_URL=http://127.0.0.1:5173`: это origin интерфейса для подтверждения корзины и ссылки на неё. Используйте `127.0.0.1` во всех адресах.

Интерактивная слайд-презентация для жюри и тезисы спикера находятся в `docs/presentation.html` и `docs/presentation.md`.


## Контракт для фронтенда

Полные запросы, ответы и ошибки описаны в [docs/API.md](docs/API.md).

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/session` | Создать/восстановить сессию, получить CSRF-токен и корзину |
| POST | `/api/chat` | Сообщение пользователя; ответ, карточки, аналоги, предложение для корзины |
| GET | `/api/cart` | Текущая демо-корзина и ссылка |
| POST | `/api/cart/confirm` | Добавить товар по `proposalId` после клика «Да, добавить» |
| POST | `/api/attachments` | Извлечь позиции из PDF/DOCX/XLSX/JPEG для проверки пользователем |

Во всех браузерных запросах используйте `credentials: "include"`. Перед подтверждением покажите точные товар, артикул, количество, город, цену и сумму из `proposal`. В `POST /api/cart/confirm` передайте `X-CSRF-Token` из `/api/session`. Сам вызов `/api/chat` никогда не меняет корзину.

## Архитектура

```text
Frontend (тимейт)
  │  JSON / multipart; cookie-сессия
  ▼
Fastify HTTP API ───────────────► сессия, CSRF, история диалога
  │
  ├─ AssistantRunner ───────────► OpenAI Responses + строгие tool calls
  │    ├─ search_products
  │    ├─ get_product_details
  │    ├─ find_alternatives
  │    ├─ get_purchase_terms
  │    └─ prepare_cart_item ────► только предложение, без записи в корзину
  ├─ EktCatalogReader ──────────► индекс поиска + EktClient ─► ekt.kz API
  ├─ AttachmentExtractor ───────► PDF/DOCX/XLSX/JPEG → позиции на проверку
  └─ DemoCartProvider ──────────► запись только после /api/cart/confirm
```

При запуске индексируются первые `EKT_INDEX_MAX_PAGES` страниц каталога (по умолчанию 20). Поиск по ним быстрый; детальные цены, характеристики и остатки читаются из EKT API. Индекс ограничен для скорости старта демо, поэтому он не гарантирует покрытие всего каталога. Увеличьте лимит после оценки времени запуска и числа страниц.

В ответах нельзя выдумывать наличие, цену, сертификаты или совместимость. Если у товара нет остатков, ассистент предлагает кандидатов в аналоги и отмечает различающиеся или неизвестные характеристики. Для сертификатов и условий покупки сообщается только то, что есть в источниках; отсутствие данных отмечается честно.

Корзина хранится в памяти процесса и служит демонстрацией сценария. При подтверждении backend заново проверяет цену, остаток в выбранном городе и кратность заказа (`KRATNOST_MIN`), отклоняет устаревшее предложение с HTTP 409 и защищает от повторного добавления того же предложения. Реального API записи в корзину ekt.kz участникам пока не предоставлено, поэтому ссылка ведёт на демо-корзину этого сервера. Для production потребуются официальный cart API, постоянное хранилище сессий и индекс всего каталога.

## Разделение работы двух участников

- Backend/AI: интеграция с EKT API и OpenAI, факты и аналоги, извлечение файлов, безопасная корзина, тесты и deploy backend.
- Frontend: чат, карточки товара и сравнение, выбор и подтверждение предложения, ссылка на корзину, адаптивность и демо-сценарий.

Каждый час фиксируем работающий checkpoint в GitHub. Перед показом запускаем `npm run build` и `npm test`.
